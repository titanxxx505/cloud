# ☁️ Alex Cloud

Alex Cloud est un site de partage de fichiers. Retrouve les fichiers mis à disposition par Alex, recherche-les par leur nom et télécharge-les en un clic. Chaque fichier dispose automatiquement de sa page avec une description et un lien à partager.

🌐 **[Accéder à Alex Cloud](https://titanxxx505.github.io/cloud/)**

## Ajouter un fichier

1. Ouvre le dossier [fichiers](./fichiers).
2. Clique sur **Add file → Upload files**.
3. Dépose ton fichier et valide avec **Commit changes**.
4. Après la mise à jour du site par GitHub, sa page est disponible en cliquant sur son nom ou sur **Voir la description**.

## Personnaliser la description

1. Sur le site, ouvre la page du fichier.
2. Clique sur **Ajouter une description sur GitHub**.
3. Remplace le texte proposé par ta description.
4. Valide avec **Commit changes** et attends la mise à jour du site.

Pour la modifier ensuite, utilise **Modifier la description sur GitHub**. Tu dois être connecté au compte GitHub autorisé à modifier ce dépôt.

Sans texte personnalisé, le site affiche une description simple avec le nom, le type et la taille du fichier. Il ne résume pas automatiquement son contenu.

Les descriptions sont enregistrées à côté des fichiers, avec le suffixe `.description.txt` (exemple : `cours.pdf.description.txt`). Ces textes ne sont pas listés comme des fichiers à télécharger. Si tu renommes un fichier, renomme aussi son fichier de description.

Les fichiers partagés sont publics.
